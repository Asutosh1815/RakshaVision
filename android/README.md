# 📱 Android Mobile Command Client

This directory contains the complete Android Studio project structure for **RakshaVision Mobile**, allowing safety supervisors and plant marshals to monitor live CCTV feeds, receive push alerts, and review incident snapshots directly on Android devices.

## Features
- **Live Stream Viewer**: Low-latency video rendering from edge RTSP/WebRTC streams.
- **Push Alerts**: Instant notifications for critical PPE violations or combustion hazards.
- **Role-Based SOPs**: On-screen emergency action steps for zone marshals.
- **APK Ready**: Standard Gradle build configuration for single-click APK compilation.
