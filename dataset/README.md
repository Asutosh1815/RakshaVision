# 📦 Industrial PPE Training Dataset

This directory contains the training and validation splits from the **Mendeley 2,286 Industrial PPE Dataset**.

## Dataset Structure
- `mendeley_ppe2286/train`: 1,828 annotated training images.
- `mendeley_ppe2286/valid`: 229 annotated validation images.
- `mendeley_ppe2286/test`: 229 annotated test images.
- `mendeley_ppe2286/data.yaml`: Dataset configuration and class definitions (`helmet`, `no-helmet`, `vest`, `no-vest`).
